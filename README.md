# TechRadar

> IT 기술 트렌드와 개발 정보를 한곳에서 탐색하고, 관심사에 맞는 콘텐츠와
> 행사를 발견하는 AI 기반 소셜 플랫폼

## 📌 프로젝트 소개

**TechRadar**는 IT 분야 종사자와 학생이 최신 기술, IT 뉴스, 기술 블로그,
컨퍼런스, 세미나, 해커톤 등의 정보를 효율적으로 탐색할 수 있도록 돕는 AI
기반 웹 서비스입니다.

여러 사이트에 흩어진 정보를 직접 찾아다니는 대신, 관심 기술과 활동을
바탕으로 개인화된 콘텐츠를 추천받고, AI 요약으로 핵심 내용을 빠르게
파악하며, SNS 형태의 피드에서 다른 사용자와 정보를 공유하고 소통할 수
있습니다.

## 🎯 기획 배경 및 목표

-   **정보 탐색 시간 단축:** 여러 사이트에 분산된 IT 콘텐츠와 행사
    정보를 한곳에서 탐색
-   **개인화된 정보 제공:** 직무, 관심 기술, 경력 수준 및 활동 이력을
    바탕으로 맞춤형 콘텐츠 추천
-   **기술 정보 이해도 향상:** 생성형 AI를 활용해 긴 기사와 기술 문서의
    핵심 내용 요약
-   **학습 및 커리어 기회 확대:** 관심 분야에 맞는 컨퍼런스, 세미나,
    해커톤 등의 행사 발견
-   **사용자 간 지식 공유:** 게시글, 댓글, 좋아요, 북마크 등을 통한 기술
    중심의 소셜 상호작용

## ✨ 핵심 기능

### 1. SNS형 IT 콘텐츠 피드

-   최신 IT 뉴스, 기술 트렌드, 개발 관련 게시글을 피드 형태로 제공
-   추천 피드와 팔로잉 피드 지원
-   게시글 작성 및 이미지·링크·해시태그 첨부
-   좋아요, 댓글, 답글, 공유 및 북마크 기능

### 2. 관심사 기반 콘텐츠 추천

-   사용자의 직무, 관심 기술, 경력 수준 및 서비스 내 활동을 바탕으로
    콘텐츠 추천
-   AI를 활용한 콘텐츠 주제와 난이도 분석
-   추천 콘텐츠와 함께 추천 이유 제공

### 3. AI 콘텐츠 요약

-   긴 IT 기사, 기술 블로그 및 공식 문서의 핵심 내용 요약
-   사용자 수준에 맞춘 설명과 주요 키워드 제공
-   원문 링크와 출처를 함께 제공해 원본 확인 지원

### 4. IT 행사 탐색 및 추천

-   컨퍼런스, 세미나, 해커톤 등 IT 행사 검색
-   지역, 날짜, 비용, 온·오프라인 방식에 따른 필터링
-   관심 분야와 참여 조건에 맞는 행사 추천
-   행사 일정과 신청 마감 정보 확인 및 알림

### 5. 자연어 검색 및 AI 어시스턴트

-   일상적인 문장으로 콘텐츠와 행사 검색
-   예: "서울에서 열리는 무료 AI 세미나 알려줘"
-   질문 의도와 검색 조건을 분석해 관련 결과 제공
-   기술 개념 질의응답과 관련 자료 추천

### 6. AI 주간 브리핑

-   한 주 동안의 주요 기술 동향과 관심 분야 콘텐츠 요약
-   유사하거나 중복된 정보를 통합해 핵심 이슈 정리
-   관심사에 맞는 추천 콘텐츠 및 행사 제공

### 7. 프로필 및 알림

-   사용자 소개, 관심 기술, 작성 게시글 및 활동 이력 관리
-   좋아요, 댓글, 팔로우 등 소셜 활동 알림
-   관심 분야의 주요 소식과 행사 마감 알림

## 🤖 AI 활용 방안

TechRadar는 생성형 AI를 단순한 챗봇이 아니라 콘텐츠 탐색과 이해를 돕는
핵심 기능으로 활용합니다.

-   **콘텐츠 분류:** 주제, 기술 분야 및 난이도에 따라 콘텐츠를 분류
-   **개인화 추천:** 사용자 관심사와 콘텐츠 특성을 비교해 추천 순위를
    결정
-   **핵심 내용 요약:** 긴 글에서 중요한 정보와 키워드를 추출
-   **행사 정보 분석:** 분야, 대상, 장소, 비용 및 일정 등 주요 조건 파악
-   **자연어 검색:** 질문에서 검색 의도와 조건을 추출해 결과 제공
-   **주간 브리핑:** 주요 기술 변화와 관련 콘텐츠를 통합해 요약

AI가 생성한 정보는 원문과 구분해 표시하며, 가능한 경우 출처와 게시
날짜를 함께 제공합니다. 근거가 부족한 내용은 확정적인 사실처럼 제시하지
않는 것을 원칙으로 합니다.

## 🏗️ 시스템 구성 개요

서비스는 다음 계층으로 구성하는 것을 목표로 합니다.

``` text
사용자
  │
  ▼
Frontend (웹 UI / SNS 피드 / 검색 / 프로필)
  │
  ▼
Backend API
  ├── 사용자 및 인증 관리
  ├── 게시글·댓글·좋아요·팔로우 관리
  ├── 콘텐츠 및 행사 검색·필터링
  ├── 저장·알림 관리
  └── AI 기능 연동
        ├── 콘텐츠 요약
        ├── 개인화 추천
        ├── 자연어 검색
        └── 주간 브리핑
  │
  ▼
Database ───── External APIs / 콘텐츠 데이터 소스
```

-   **Frontend:** 사용자 입력, 피드 및 검색 화면, 게시글과 분석 결과
    표시
-   **Backend API:** 비즈니스 로직, 요청 검증, 인증, 데이터 처리 및 외부
    서비스 연동
-   **Database:** 사용자, 게시글, 댓글, 관심사, 콘텐츠, 행사 및 활동
    기록 저장
-   **AI Module:** 콘텐츠 요약, 추천, 분류 및 자연어 질의응답
-   **External Data Sources:** 최신 IT 뉴스, 기술 콘텐츠 및 행사 정보
    수집

> 위 구조는 프로젝트의 개념적 아키텍처입니다. 실제 기술 스택과 세부
> 구성은 구현 단계에서 확정합니다.
